# План разработки Steal a Kaiju

Выбор: **Steal a Kaiju** (steal-tycoon). Обоснование в `GDD.md`: самый быстрорастущий жанр 2026 года,
MVP вдвоём за 3–5 недель, много способов монетизации без pay-to-win стрельбы.

Инструменты: Rojo 7.7 (`default.project.json`), весь мир и модели строятся кодом из частей.
Проверка: `tools/check.sh` (компиляция всех файлов), затем Studio через Vinegar.

## Этап 1 — ядро (MVP-цикл) ✅ код написан, ждёт проверки в Studio
- [x] Rojo-проект, Net (remotes), Config, каталог кайдзю, форматирование чисел
- [x] Карта: центральный конвейер, 8 баз (по 4 с каждой стороны), спавн дома
- [x] Сохранения (session lock, как в Frontline): деньги, кайдзю по слотам, ребёрты, статистика
- [x] Конвейер: кайдзю едут по ленте, покупка через ProximityPrompt, взвешенная редкость
- [x] Переноска: кайдзю над головой, замедление по размеру, доставка на свою базу
- [x] Доход: банк базы копится, плита сбора, оффлайн-доход (25%, до 8 ч)
- [x] Рост S → M → L → XL → Titan (множитель дохода, штраф к скорости переноски)
- [x] Кражи: взять у чужого, донести до себя; при смерти/ударе — возврат владельцу
- [x] Замок базы на 60 с (кнопка на базе), лазерный барьер выталкивает чужих
- [x] Бита «Bonk»: оглушает и выбивает украденного кайдзю
- [x] Продажа своего кайдзю (50%), ребёрт (×1.5 доход, +1 слот)
- [x] HUD: деньги, доход/с, уведомления, кнопка «Домой», ребёрт

Исправлено после проверки:
- HUD всегда показывал $0: перепутаны аргументы TweenInfo (EasingStyle/EasingDirection).
- После ребёрта игрок оставался с $0 и без кайдзю и не мог ничего купить → теперь $50 стартовых.
- Украденный кайдзю терялся, если владелец выходил или занимал освободившийся слот → слот владельца резервируется до конца переноски и сохраняется.
- Баланс растянут с ~40 минут до ~суток игры (docs/BALANCE.md).

Известные ограничения: рост идёт только пока владелец онлайн.
