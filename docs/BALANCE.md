# Баланс экономики

Цифры в `src/shared/Kaiju.luau` (цены и доход) и `src/shared/Config.luau` (стадии роста, ребёрт).
Проверялось симуляцией: игрок покупает с ленты лучшего кайдзю, какого может себе позволить,
продаёт худшего, когда слоты заняты, и делает ребёрт, как только хватает денег.

## Окупаемость (цена / доход на стадии S)
| Редкость | Цены | Окупаемость |
|---|---|---|
| Common | $15 – $500 | 20–31 с |
| Rare | $2K – $77K | 1–2 мин |
| Epic | $312K – $11.4M | 4–10 мин |
| Legendary | $41M – $336M | 20–40 мин |
| Mythic | $1.44B – $11.5B | 1–2 ч |
| Secret | $43B – $216B | 4–5 ч |

Ребёрт: $200M × 5ⁿ, даёт +50% дохода и +1 слот, после него $50 стартовых.

## Результат симуляции (онлайн-время)
| Событие | Игрок один на ленте | Делит ленту (30% покупок) |
|---|---|---|
| Первый Epic | 15 мин | 18–28 мин |
| Первый Legendary | ~55 мин | ~1.1 ч |
| Ребёрт 1 | ~1.2 ч | ~1.4 ч |
| Первый Mythic | 3.6–4.6 ч | 5–7 ч |
| Первый Secret | 8–13 ч | 14–20 ч |
| Ребёрт 8 | ~24 ч | — |

До правки (цены Mythic/Secret $30–58M, ребёрт $1M) вся игра проходилась за 30–45 минут,
после чего деньги копились без цели. Кражи и оффлайн-доход в симуляции не учтены: они ускоряют рост.
