Файлы: src/server/Conveyor.luau и src/server/Carry.luau. Реализуй строго по разделам "server/Conveyor.luau" и "server/Carry.luau" в docs/ARCH.md, используя уже написанные src/server/Data.luau, Map.luau, src/shared/Kaiju.luau, KaijuModel.luau (прочитай их API). Модуль src/server/Bases.luau пишет другой агент параллельно — используй только его API из ARCH.md (baseOf, ownerOf, addKaiju, removeKaiju, slotModel, isLocked, kaijuAdded, unlockedSlots). Conveyor: движение моделей по ленте плавно (Heartbeat, PivotTo), ProximityPrompt Buy с ценой, Stats.Bought++. Carry: промпт Steal на моделях из Bases.kaijuAdded, переноска над головой (Weld к HumanoidRootPart, клон/новая модель через KaijuModel.build), замедление, таймаут, возврат при смерти/выходе/ударе, доставка по Zone, Bonk Tool (Handle из частей, анимация взмаха через поворот Grip или Tween, серверная валидация дистанции и кулдауна), уведомления Robbed/Notify. Если вор вышел из игры — кайдзю возвращается владельцу. Нельзя красть больше одного одновременно.
